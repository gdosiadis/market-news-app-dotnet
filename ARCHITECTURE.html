Overview

01  The Big Picture

Two apps share one SQLite database and one library layer.

ComponentRole
MarketNewsApp/Console pipeline — scrape → clean → cache → summarize → email. Runs daily.
MarketNewsAdmin/ASP.NET MVC web portal — configure the pipeline, view dashboards, browse archived reports.
MarketNewsApp.Tests/Unit tests.

How data flows

One-sentence mental model: the Admin portal writes config into SQLite, the pipeline reads that config to scrape 7 sites with Playwright, summarizes them via a pluggable AI agent, renders an email, and both apps run as Docker containers sharing one database.

02  Pipeline App — Entry & Services

The console app that does the daily work.

Entry point & config

FileWhat it does
Program.csMain entry. Parses CLI flags (--now, --test, --source, --fresh, --debug-dom), sets up Serilog, runs DB migrations, then drives the 5-step pipeline (RunPipeline). Holds the scheduler loop, checkpoint fallback, and failure-alert email.
MarketNewsApp.csprojProject file — NuGet deps (Playwright, MailKit, EF Core, Serilog, Scriban).
README.mdHuman docs: source list, setup, cache behavior.
Models/Models.csCore data shapes: SiteConfig, ScrapedSite, SourceStatus enum, summary types.

Services — the pipeline stages

FileWhat it does
Scraper.csPlaywright automation. Loads each site, dismisses overlays, extracts text, and captures chart/table screenshots from the live page (ground truth, never AI-rendered).
AiSummarizer.csPer-source Greek AI summaries, then a synthesized overview. Handles transient-error retries.
EmailSender.csRenders the Scriban HTML template and sends via SMTP (MailKit). Also sends operational alerts.
ScrapeCache.csCaches same-day scrape results by content hash.
SummaryCache.csSame idea for AI summaries (per-source + final synthesis).
PipelineCheckpointStore.csPersists per-source checkpoints so a crashed run resumes instead of restarting.
ConfigurationService.csLoads RuntimeConfiguration (sources, schedule, email, flags) from SQLite.
ReportArchive.csSaves generated HTML reports for the admin portal.
AuditLogger.csRecords audit-trail events.
ProductionMaintenance.csStartup housekeeping (DB pragmas, cleanup) before the pipeline.
SmtpResilience.csRetry/backoff for flaky SMTP sends.
